# Grindstone

> *Grindstone* (n.): an old artifact that mills your opponent; also what you do on the ladder. This server sharpens your deck.

An MCP server that takes an MTG Arena decklist, validates it, rates its power level (casual → competitive), and suggests upgrades that fit your wildcard budget.

*Work in progress.*
