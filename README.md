# Whetstone data branch

Generated by the daily `data-deploy` workflow; do not edit by hand.

- `current/<game>/`: latest good data per game (custody classes A, A-SA and A-NC-SA only). `_files.json` lists every file's custody class.
- `history/YYYY/MM/DD/<game>.json.gz`: daily summaries (meta plus small class-A files).
- `status.json`: result of the last run per game, including sources that served last-good data.
- `LICENSE` and `NOTICE.md`: the licence of Whetstone's own data, and every source's licence, credit and copyright notice.

Layout, schemas, licences and attribution rules: https://github.com/JollyKrampus/whetstone/blob/main/docs/DATA.md
Short-lived (C) and community-derived (D) data and anything licensed for display only (B) is never stored here.
